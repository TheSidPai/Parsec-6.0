# Parsec 6.0 — Harry Potter Tech Fest Website

A Harry Potter-themed tech fest website built with React and Node.js. Features house-based personalization, event management, and an immersive magical UI.

## Tech Stack
- **Frontend:** React, React Router
- **Backend:** Node.js, Express (handled separately)
- **Auth:** Aadhaar-based authentication

## Features
- 🏰 House-themed dashboard (Gryffindor, Slytherin, Hufflepuff, Ravenclaw)
- 📅 Event browsing and registration
- 🎫 Ticketing system with QR codes
- 🏆 Leaderboard and inter-house competitions
- 📜 Multi-step signup with Aadhaar verification

Built for IIT Dharwad's Parsec 6.0 Tech Fest.
